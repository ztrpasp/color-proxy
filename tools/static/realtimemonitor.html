浏览器直连 172.10.9.2:8000：新连接先为端口级 SID 发 GET（D19），请求行一到再为这条 URL 的 SID 发 GET（D20），RM 放行后请求字节才进隧道。

响应没有固定 Content-Length。源站每写一个事件就是一个 TCP 段，封进 CoLoR DATA 原样送达，中间没有任何一跳缓冲整条响应。

点击停止后浏览器关闭 TCP 连接；FIN 经隧道到达源站，源站下一次写入失败即结束这条流，不需要额外的取消报文。
