CoLoR 正向代理
跨域 Web 取回展示页

这一页比 hello.html 大得多——它会被切成多个 1200 字节的 DATA 分片在网络中传输，再到消费端按序重组。你现在能完整看到它，就说明 分片传输与重组工作正常。

① 先拉

浏览器请求被消费端拦下，转成 CoLoR GET 发往 RM。

② 建隧道

提供端回送隧道 DATA，带回反向 PID 序列，确定回址。

③ 后推

消费端用 ACK(B=1) 把原始 HTTP 请求推给提供端回源。

④ 回程

响应按分片封进 DATA 发回，best-effort、无重传。

握手流程

GET → 隧道 DATA → ACK(载 HTTP 请求) → 响应 DATA（分片）

样例端点

条目 id 走 query ?id=N：增删改查共用 /api/items 一条 SID， 且 ?id= 不入 SID、仍原样透传到源站。

方法路径说明
GET/showcase.html本页（跨多分片）
GET/api/items列出全部条目
GET/api/items?id=N取单条 / 404
POST/api/itemsJSON body 创建，返回 id
PUT/api/items?id=N覆盖更新 / 404
DELETE/api/items?id=N删除 / 404
